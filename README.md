# Ovalis

Ovalis est un jeu d'aventure. Tu te promènes dans un pays imaginaire, tu te fais des amis créatures, et tu les entraînes au combat.

Le jeu est en français. Il se joue le téléphone couché (à l'horizontale).

## Installer le jeu sur un téléphone Android

1. Ouvre l'application **Chrome**.
2. Va à l'adresse : https://yanndom61.github.io/ovalis/
3. Tourne le téléphone à l'horizontale.
4. Appuie sur les **trois points** en haut à droite.
5. Appuie sur **Installer l'application** ou **Ajouter à l'écran d'accueil**.
6. Confirme. Une icône Ovalis apparaît sur ton écran d'accueil.
7. Ouvre le jeu depuis cette icône. Il passe en plein écran.

La première ouverture a besoin d'internet. Ensuite, le jeu marche même sans réseau.

Ta partie s'enregistre toute seule sur le téléphone. Dans les réglages, tu peux aussi copier un fichier de sauvegarde pour le passer sur un autre téléphone : « Copier la sauvegarde dans un fichier », puis sur l'autre téléphone « Lire un fichier de sauvegarde ».

## Jouer

- Pose le pouce gauche sur l'écran : un stick apparaît, tu marches avec.
- Le bouton **A** sert à parler, confirmer et attaquer.
- Le bouton **B** ouvre le menu, ou revient en arrière.
- Sur un ordinateur : les flèches pour marcher, **Z** pour A, **X** pour B.

Dans cette version, tu crées ton héros à Valclair, tu choisis un compagnon, tu explores la ville et le Sentier des Roseaux, tu te bats, tu peux capturer un compagnon sauvage et soigner ton équipe au Relais Vital. La ville de Portbrume est visible, mais encore fermée.
